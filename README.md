# DRONOU — site

Site estático do **DRONOU** (*Dronou? Então dronou legal.*): trilhas interativas de ANATEL, SISANT e SARPAS NG, simuladores, simulado da prova ANAC e ferramentas gratuitas para pilotos de drone no Brasil.

## Publicação (GitHub Pages)

Este repositório já está no formato certo: o `index.html` fica na raiz.

1. `Settings` → `Pages`
2. **Source:** `Deploy from a branch`
3. **Branch:** `main` • pasta `/ (root)` → **Save**
4. Aguarde o link `https://SEU-USUARIO.github.io/dronou/` ficar verde

## Domínio próprio (quando registrar)

1. Registre `dronou.com.br` (Registro.br) e, se quiser, `dronou.com`
2. No repositório: `Settings` → `Pages` → **Custom domain** → `dronou.com.br`
3. No Registro.br, aponte o DNS conforme a tela do GitHub indicar e ative **Enforce HTTPS**

## Estrutura

- `index.html` — o site (arquivo único, com as logos embutidas)
- `materiais/` — PDFs e ferramentas para download
- `logo-oficial.webp` / `icone-dronou.webp` — arte da marca
